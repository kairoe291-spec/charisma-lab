# 一、版本概述

## 1.1 版本目标

v0.1 是 Charisma Lab 的第一个可运行版本。

核心目标：

> 建立一个能够记录、管理和追踪个人成长过程的离线优先 Web 应用基础框架。

本版本不追求完整功能，而优先验证：

- 产品方向是否成立；
- 数据模型是否合理；
- 用户成长闭环是否能够运行；
- 后续云同步和 AI 扩展是否具备基础。


---

# 二、产品定位


Charisma Lab v0.1 是：

> 一个帮助用户记录个人成长目标、学习过程、训练实践和思考复盘的个人成长管理工具。


核心闭环：

```text
设定目标

↓

学习内容

↓

完成训练

↓

记录经历

↓

复盘总结

↓

持续成长
```

# 八、当前限制


## 1. 无账号系统


原因：

v0.1采用本地优先模式。


影响：

数据只存在当前设备。


计划：

v0.2 Cloud Sync。


---

## 2. 无云同步


原因：

优先验证：

本地数据模型。


计划：

增加：

- Supabase
- Sync Engine
- Conflict Manager


---

## 3. 内容体系未完整展开


当前：

只有课程结构。


未来：

v0.3增加：

- 36+课程
- 情景模拟
- 测试系统


---

## 4. 无AI能力


原因：

AI需要稳定用户数据。


计划：

v0.4 AI Coach。
