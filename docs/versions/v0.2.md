## v0.2 执行范围与发布门槛

基线为已发布的 `v0.1.1`（标签指向 `5aeda83d25ee7b98bc4f48bdecdb119c55bd443e`）。保持 IndexedDB 本地优先、游客模式和离线编辑可用；云端是用户选择配置、登录后才启用的同步能力。当前仓库的本地模拟与 PGlite 测试不能替代真实云端验收。独立任务 [CLOUD-ACCEPTANCE-01](../cloud-acceptance-checklist.md) 可与开发并行准备，但通过它是 v0.2 正式发布的必要条件。

### 已有数据类型与同步范围

以 `src/domain/types.ts` 的 `RecordKind`、`src/data/local/schema.ts` 的单一 `records` Store 和现有 SQL `user_records.kind` 约束为准。下表 12 类均纳入账号空间的同步验收；游客空间继续仅在本机保存，除非用户明确选择迁移。这里的“纳入”是 v0.2 目标，不表示已通过真实云端验证。

| 范围 | 实际记录类型 | v0.2 验收要求 |
| --- | --- | --- |
| 核心：学习记录 | `courseProgress`、`lessonNote` | 进度、笔记及收藏可保存、继续编辑并跨设备恢复；笔记并发修改不得静默覆盖或丢失 |
| 核心：训练记录 | `trainingRecord` | 完成记录及心得跨设备新增、更新、软删除 |
| 核心：成长日志 | `journalEntry` | 正文、标签跨设备恢复；同时编辑时保留双方版本并可手动解决 |
| 核心：测评数据 | `assessmentResult`、`selfEvaluation` | 跨设备逐条取回并核对多次提交生成的测评结果与自评记录，包括数量、ID、提交时间及答案或分数；不能生成模拟分数，不要求编辑、删除既有结果或回滚到旧版本 |
| 其他私人数据 | `profile`、`growthGoal`、`userInterest`、`appSettings` | 目标、兴趣、资料及当前主题设置按账号隔离并完成往返核对 |
| 其他学习与训练数据 | `trainingTask`、`scenarioAttempt` | 自定义任务及情景练习/反思按账号同步，关联记录可正常读取 |

静态课程、题库和任务模板仍随应用发布，不上传为每个用户的私人副本。Outbox、同步元数据、冲突处理记录、安全快照和认证令牌是本机或系统状态，不作为上述业务记录同步；软删除标记随对应私人业务记录传播。备份导入不继承原文件的账号身份或上传授权。

### 责任边界与待验收流程

UI 经 Service → Repository 写入 Dexie；业务记录与 Outbox 在同一本地事务提交后，才能提示“已保存到本机”。Sync Engine 读取账号空间队列，通过受会话约束的 Supabase Transport 调用版本条件写入 RPC，并分页拉取云端记录；Supabase Auth 管认证，PostgreSQL/RLS 管服务端归属与授权。业务组件不直接以远端 API 代替本地 CRUD。“已同步到云端”只能在远端确认后显示；离线、失败和冲突状态分别呈现，不能把待同步当作成功。

- [ ] **认证与隔离**：验证首次邮箱 OTP 登录/创建账号、退出、会话恢复及离线已缓存身份；账号 A 退出后账号 B 看不到 A 的本地或远端私人记录。现有实现使用邮箱 OTP，不以密码认证作为本版承诺。
- [ ] **游客迁移**：登录时展示游客记录数量并提供合并、保留不合并、取消选择及备份入口；不自动清空游客数据。模拟中断与重复迁移，结果不重复、不越过当前账号空间。
- [ ] **本地优先**：断网时学习进度与笔记可保存和继续编辑，训练记录与成长日志可按现有功能新增、修改和软删除，测评/自评可多次提交并逐条读取各次提交生成的记录；刷新后核对各类记录。本地事务失败不能误报已保存，且不得执行依赖未保存编辑的危险操作。
- [ ] **可靠双向同步**：验证自动触发、手动触发、网络恢复、重新登录或页面激活后的上传与拉取；队列失败保留并指数退避。响应丢失后重发同一 `mutationId` 不产生重复记录或错误覆盖；分页快照变化时不漏记录。
- [ ] **冲突与删除保护**：两个设备基于同一服务端版本编辑同一日志时检测冲突，保留本地和云端内容，提供保留本地、保留云端、手动合并或暂缓；课程笔记的并发修改按独立云端清单先确认适用策略并验收，不得静默覆盖或丢失。不能用设备时间静默裁决冲突。软删除与 Tombstone 跨设备生效，旧设备不能复活记录。
- [ ] **账号与云端安全**：在真实项目验证 SQL 迁移、GRANT、RLS 两账号读写隔离及 RPC 原子版本比较；前端仅使用公开密钥，不提交管理员凭据。
- [ ] **数据范围核对**：学习进度与笔记验证保存、读取、继续编辑和跨设备恢复；训练记录与成长日志验证新增、读取、更新、软删除及跨设备恢复；测评结果与自评验证多次提交后跨设备逐条取回记录，核对数量、ID、提交时间及答案或分数，不要求修改、删除既有结果或回滚到旧版本。其余六种记录类型逐项完成账号隔离和往返核对，未覆盖者须明确列为未完成。
- [ ] **独立发布门槛**：完成 [CLOUD-ACCEPTANCE-01](../cloud-acceptance-checklist.md)，记录真实托管环境、实际邮件流程、两个独立浏览器或设备、缺陷与修复提交；未通过不得宣称 v0.2 生产环境验收完成。

非目标：12 大模块课程内容的大规模扩充、AI Coach、整体 IndexedDB/数据库重构、无关性能优化及秒级推送。既有主包体积与构建注释警告另行跟踪，不因它们改变本版云端验收边界。
