# 六、AI Agent体系


# Agent 01

# Growth Coach Agent（成长教练）


## 定位


用户的长期成长伙伴。


---

## 输入


读取：

- 用户目标
- 学习记录
- 训练记录
- 成长日志
- 测评结果


---

## 输出


生成：

- 今日建议
- 本周计划
- 成长反馈
- 行为调整建议


---

## 示例


用户：

> 最近感觉自己表达越来越差。


AI分析：

```text
过去30天：

表达训练：
12次

公开表达：
3次

自我评分：
下降


建议：

1. 恢复每日60秒表达训练

2. 增加观点输出

3. 每周完成一次公开表达
```


---

# Agent 02

# Communication Coach（表达教练）


## 定位


提升：

- 表达能力
- 逻辑能力
- 沟通质量


---

## 功能


用户输入：

一段文字或观点。


AI分析：

- 结构
- 逻辑
- 语言
- 说服力


---

## 示例


输入：

> 我觉得AI未来会影响很多行业。


AI反馈：

问题：

观点正确，但缺少：

- 具体案例
- 个人立场
- 逻辑展开


优化：

提供：

结构化表达模板。


---

# Agent 03

# Reflection Agent（复盘助手）


## 定位


分析用户经历。


---

## 输入：

成长日志。


例如：

```text
今天参加社团活动。

感觉和别人聊天比较紧张。
```


---

## 输出：


分析：

```text
事件：

陌生社交


可能原因：

准备不足


可优化：

提前准备3个开放问题
```

# 九、长期记忆系统


## 为什么需要Memory？


普通聊天：

每次重新开始。


成长助手：

需要知道：

“你是谁，你过去发生了什么。”


---

## Memory类型


## Short-term Memory


短期：

当前对话。


---

## Long-term Memory


长期：

用户成长历史。


---

## Structured Memory


结构化信息：

例如：

```json
{
"goal":"提升表达能力",

"weakness":"容易紧张",

"strength":"学习能力强"
}
```

# Prompt原则


避免：

简单问答。


采用：

角色 + 背景 + 数据 + 目标 + 输出格式。


---

示例：


```text
你是一名个人成长教练。

用户目标：

提升表达能力。

根据用户最近30天训练数据：

分析：

1. 当前状态

2. 最大问题

3. 下一步训练方案
```

# 十四、AI安全设计


## 数据隐私


用户成长数据：

默认：

私密。


---

## AI读取权限


AI只能读取：

用户授权数据。


---

## 敏感内容处理


避免：

- 过度判断用户人格；
- 给出绝对化评价；
- 替代专业人士。
