# Charisma Lab v0.2 Cloud Sync Edition

> Release Documentation  
> Personal Growth Operating System

版本：

`v0.2.0`

版本名称：

**Cloud Sync Edition（云同步版）**

发布日期：

计划：2026-11 ~ 2027

状态：

规划中；账号、同步引擎及 SQL 迁移已有代码和本地自动化测试，但真实托管 Supabase 项目的迁移、认证及双设备同步尚未验收，不能标为云同步正式发布。

# 一、版本概述

## 1.1 版本目标

v0.2 是 Charisma Lab 从单机应用走向产品化的重要版本。

核心目标：

> 实现用户账号体系、云端数据存储以及多设备同步能力。


完成后：

用户可以：

- 在电脑记录成长；
- 在手机查看数据；
- 更换设备后恢复成长档案；
- 安全保存多年成长记录。

# 4. Sync Queue同步队列


## 功能


记录：

所有等待同步的数据。


---

## 数据结构


```typescript
interface SyncQueue {


id:string;


entityType:string;


entityId:string;


operation:

"create"

|

"update"

|

"delete";


payload:any;


status:string;


retryCount:number;


createdAt:Date;

}
```


---

## 同步状态


支持：


|状态|说明|
|-|-|
|pending|等待同步|
|syncing|同步中|
|success|完成|
|failed|失败|
|conflict|冲突|
