# Charisma Lab 产品路线图

> Personal Growth Operating System  
> 个人魅力成长实验室版本规划

## 一、项目愿景

**Charisma Lab（个人魅力成长实验室）** 是一个面向长期个人成长的数字化平台。

它不是一个简单的知识网站，而是一个帮助用户：

- 认识自己
- 学习能力
- 训练行为
- 记录成长
- 获得反馈
- 持续优化

的个人成长操作系统。

核心成长闭环：

```
认识自己
    ↓
学习知识
    ↓
场景训练
    ↓
现实实践
    ↓
记录复盘
    ↓
阶段评估
    ↓
调整方向
    ↓
持续成长
```

# v0.1.1 Architecture Upgrade

## 版本定位

> 从Demo项目升级为长期可维护的软件项目。

这是进入长期开发前的重要架构升级。

---

## 主要目标

### 1. 项目结构优化

调整为：

```
src

├── features
├── data
├── content
├── services
├── types
├── shared
└── pages
```

实现：

- 页面与业务逻辑分离
- 数据层独立
- 内容数据独立


---

## 2. 数据架构升级

建立：

```
data

├── local
│
├── repositories
│
└── migrations
```

实现：

- 数据访问层
- 数据版本迁移
- 数据结构管理


---

## 3. 内容系统独立化

课程内容从代码中抽离：

```
content

├── modules
├── lessons
├── scenarios
├── questions
└── tasks
```


未来新增课程：

只需要增加内容文件。

无需修改核心代码。


---

## 4. 工程质量提升

增加：

- ESLint
- TypeScript严格模式
- 自动化测试基础
- README文档
- 项目架构文档


---

## 验收标准

完成后：

新增功能不会破坏已有系统。

项目具备持续开发能力。


---

# 核心功能

## 用户系统

实现：

- 注册登录
- 游客模式
- 用户身份管理
- 数据归属隔离


---

## 云端数据库

引入：

- Supabase
- PostgreSQL
- Row Level Security


保存：

- 学习记录
- 训练记录
- 成长日志
- 测评数据


---

## 同步系统

实现：

```
本地数据库

↓

Sync Queue

↓

云数据库

↓

其他设备
```


支持：

- 自动同步
- 手动同步
- 网络恢复同步
- 同步失败重试


---

## 冲突处理

解决：

多个设备修改同一内容的问题。


支持：

- 冲突检测
- 版本比较
- 手动合并


---

## 验收标准

用户可以：

电脑记录成长日志。

手机打开后同步查看。

断网情况下继续使用。

联网后自动同步。

# 四、开发原则

## 原则1：数据优先

用户成长数据是核心资产。

任何功能开发必须考虑：

- 数据保存
- 数据迁移
- 数据安全


---

## 原则2：真实可用

拒绝：

- 假按钮
- 假数据
- 假同步
- 随机评分


---

## 原则3：持续迭代

每个版本：

必须：

- 有明确目标
- 有验收标准
- 有版本记录


---

## 原则4：长期主义

Charisma Lab不是短期项目。

目标：

通过几年持续迭代，

打造一个真正属于自己的：

**个人成长操作系统。**
